# 原始资产整理（项目素材来源与处理台账）

> 正式交付物 ｜ 编制：市场团队 ｜ 基线版本：2.0.0 ｜ 日期：2026-09-19

**一句话结论**：本项目素材分两类——外部输入资产（课程规格、参考 PDF/文档、v1.0 方案、面试题、架构图）与由脚本生成的**自有可复现资产**（13 份样例合同、黄金标注、14 套示范条款、32 条规则）；处理原则为"原文逐字保留、只做结构化与可视化包装、不增删要点"。

---

## 1. 素材处理原则（硬约束）

| 原则 | 含义 | 落地方式 |
| --- | --- | --- |
| 原文逐字保留 | 不篡改进货素材的措辞与数字 | 引用基线数字，不重写、不四舍五入 |
| 只做结构化 | 把散落信息整理成表/树/状态机 | 本文档的清单与对比表 |
| 只做可视化包装 | 用图/表呈现，不改结论 | 雷达图、时间轴、全景表 |
| 不增删要点 | 不加油添醋、不漏关键约束 | 红线、HITL 动作、误报机制全保留 |
| 不确定即标注 | 推断内容显式声明 | 竞品文档全部"基于公开资料推断" |

| 目的 | 命令 | 预期结果（基线第八章） |

| 接口冒烟 | `python tools/smoke_api.py` | 64 项全部通过 |
