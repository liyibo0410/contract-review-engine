## 四、三个必须记住的判断

### 判断一：规则引擎下判定，大模型只做表达

法务场景的结论要**可解释、可复核、可追溯、可审计**。大模型自由判断无法满足这四条。
因此判定 100% 由 32 条 YAML 规则完成，大模型只解释成因、润色建议、检测跨条款矛盾，
且 Prompt 中明确禁止新增或修改风险项，输出必须过结构校验，失败即降级。

### 判断二：证据链到字符级

每条风险都必须能落到全文字符串的 `[char_start, char_end)` 区间。
DOCX / PDF / OCR 三种来源映射到同一坐标系，因此前端只需要**一种高亮逻辑**，
而法务可以**逐字核对**系统凭什么这么判。

### 判断三：只写意见，不改结论

系统**不存在**任何通过 / 拒绝 / 转交 / 撤回的接口。
回写前强制 DRY_RUN 预览，回写靠「合同编号 + 附件 SHA256 + 规则版本号」三键幂等，
任何下游异常落入 `failed` 并保留重试入口。审批结论永远由人做出。
