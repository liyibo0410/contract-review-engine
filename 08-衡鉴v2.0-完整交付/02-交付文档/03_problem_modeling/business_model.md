# 衡鉴 2.0 · 业务模型摘要（精简版）

> **一句话结论**：衡鉴是一套"合同审批前置的风险审查辅助系统"——解析三类合同文件、用确定性规则 + 大模型解释产出字符级风险清单与修改建议，并以评论形式写回审批单，全程不改审批结论。

---

## 1. 解决什么

- **看不完**：合同篇幅长（演示样例单份约 4 页 / 1245 字 / 10 条款），人工逐条核对不可持续。
- **看不准**：同一表述在不同业务视角风险相反，需按采购/销售/服务/劳动做 `{我方}/{对方}` 实例化判定。
- **说不清**：风险必须带原文字符区间 + 法条依据 + 修改建议，否则意见无法在审批流中流转。

## 2. 服务谁

| 角色 | 频次 | 核心诉求 |
| --- | --- | --- |
| 送审业务方 | 中频 | 上传即得风险地图 |
| 审查法务 | 高频 | 双栏核对、改判、采纳建议、回写 |
| 合规维护者 | 低频 | 改规则 + 跑回归评测 |

## 3. 价值主张

- **可定位**：每条风险落到 `full_text` 的 `[char_start, char_end)`，三格式统一高亮。
- **可信任**：风险等级由 32 条 YAML 确定性规则判定（可复现、可审计），LLM 只解释/润色/查矛盾，超时即降级。
- **可回写**：仅写审批单评论区，幂等三键防重复，DRY_RUN 预览兜底。

## 4. 核心能力边界

| 做 | 不做 |
| --- | --- |
| 解析 DOCX/PDF/扫描件 | 不做审批决策（无通过/拒绝动作） |
| 规则 + LLM 双引擎风险识别 | 不做合同起草 |
| 原文高亮 + 采纳/改写建议 | 不出正式法律意见书 |
| 评论回写（仅评论区） | 不替代法务（结论须人确认） |

## 5. 关键数据（基线实测）

- 规则库 32 条（高 11 / 中 13 / 低 8），8 种判定类型，14 套示范条款。
- 黄金样例 13 份：解析成功率 100%、高风险召回 100%、误报 0、准确率 100%、平均解析 ≈700ms。
- 工程：SQLite 单文件、FastAPI 29 路径、原生前端 4 页、39 单测 / 64 冒烟 / 8 步演示全通过。

## 6. 商业模式锚点

系统定位为"审批流中的智能审查节点"，不掌握审批权、不替代法务，而是把法务从重复核对中解放出来，聚焦真正的高风险判断——这是它能合法、可信落地的关键。
