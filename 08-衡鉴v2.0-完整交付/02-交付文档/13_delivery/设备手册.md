# 衡鉴 · 设备手册（操作者使用说明）

> **一句话结论**：本手册面向**不写代码的使用者**（法务审查人 / 业务经办人 / 系统管理员），
> 按"我该点哪里、会发生什么、出问题怎么办"的视角写，
> 读完即可独立完成一次完整的合同审查与会签。

---

## 一、开始之前

| 项 | 说明 |
| --- | --- |
| 我需要装什么 | 不需要。由管理员提供访问地址（内网）即可，浏览器用 Chrome 或 Edge |
| 我的账号 | 当前版本**无需登录**。生产环境的账号与权限见管理员手册【未开发】 |
| 我能看到什么 | 取决于给我的地址：全部审查任务 / 某一份合同的工作台 |
| 我绝对不能做什么 | 系统**不提供**任何"通过 / 拒绝 / 转交 / 撤回"操作 —— 这些仍由审批系统完成 |

**先记住三件事**：

1. 系统给的是**审查意见**，不是审批结论；最终决定始终由审批人作出。
2. 每条风险都可以**点到原文那一句**，可以逐字核对它凭什么这么判。
3. 写回审批系统前，一定会先给你看一遍要写什么（预览）。

## 二、三种角色怎么用

### 2.1 业务经办人（提交与跟进）

| 步骤 | 操作 | 位置 |
| --- | --- | --- |
| 1 | 点右侧「**接入合同**」区域，选择或拖拽合同文件 | 审查大盘右侧 |
| 2 | 填写"申请人 / 送审部门"，业务类型建议**显式选择**（采购 / 销售 / 服务 / 劳动） | 同上 |
| 3 | 观察右侧「**实时流水线**」，进度条走满即为完成 | 同上 |
| 4 | 点开该合同，查看风险结果与整改建议 | 工作台 |
| 5 | 点顶部「导出报告」下载 PDF，用于内部沟通 | 工作台顶栏 |

> **业务类型为什么重要**：同一个条款（例如"知识产权归甲方所有"）在采购合同里对我方有利、
> 在销售合同里对我方不利。系统靠业务类型判断"我方"是哪一方。
> 选错业务类型会导致该报的没报、不该报的报了 —— 这是**使用者唯一能显著影响结果准确性的输入**。

### 2.2 法务审查人（复核与出意见）

| 步骤 | 操作 | 位置 |
| --- | --- | --- |
| 1 | 从大盘点开待复核合同（高风险排在最上面） | 大盘 |
| 2 | 点右侧任一条风险卡 → 左侧**自动跳页并高亮**对应原文 | 工作台 |
| 3 | 在原文里用鼠标**划选**一段话 → 弹出该片段涉及的风险（反查） | 工作台左侧 |
| 4 | 阅读每条风险的「成因 / 依据 / 推荐修改条款」（点开折叠区） | 工作台右侧 |
| 5 | 点「**采纳建议**」，可直接编辑条款文本后再确认 | 风险卡底部 |
| 6 | 切到「结论与回写」标签，在「**法务批注**」里补充你的意见 | 工作台右侧 |
| 7 | 在「人工审核」区选择：**同意结论 / 修改后确认 / 驳回并重新审查** | 同上 |
| 8 | 点「预览意见（DRY_RUN）」确认将写入的内容 | 同上 |
| 9 | 点「**写回审批意见**」完成回写 | 同上 |

**键盘快捷键**（法务高频使用者建议记住）：

| 键 | 作用 |
| --- | --- |
| `j` / `k` | 下一条 / 上一条风险项（同步滚动左侧原文） |
| `Enter` | 采纳当前选中的风险建议 |
| `/` | 聚焦到"自然语言检索"输入框 |
| `Esc` | 退出输入框 |

**"修改后确认"怎么用**：如果系统给的**等级判断偏了**（例如把某个中风险判成了高风险），
用「修改后确认」逐条调整等级或改写建议，确认后系统会**自动重算综合风险等级与审查结论**。
全程留痕，可以看到谁在什么时候改了什么。

**"驳回"什么时候用**：只有当系统结论**存在实质错误**时才用（例如风险点在本合同附件里已另行约定）。
驳回会清空本次审查结果并自动重跑，且**在重新审查完成前禁止回写**。

### 2.3 系统管理员（规则与观测）

| 任务 | 操作 | 位置 |
| --- | --- | --- |
| 查看规则库 | 打开「合规规则与模板」，左侧按条款类型分组展示 | 规则页 |
| 调整某条规则 | 点规则 → 改等级 / 成因说明 / 法律依据 → 保存 | 规则页右侧 |
| 查看示范条款 | 页面下半部分「标准示范条款库」 | 规则页 |
| 运行评测 | 点「运行评测（全量 13 份）」 | 评测页 |
| 看系统健康 | 顶栏右上角三个指示灯：规则库 / 语义层 / OCR | 全局 |
| 看处理链路 | 工作台 → 任务详情里的审计留痕（或用接口 `/api/contracts/{id}/audit`） | 工作台 / 接口 |

> ⚠️ **改规则前必读**：规则库是系统的判定依据，改动会影响所有合同的结论。
> 改完**必须**去评测页跑一遍全量评测，确认"高风险召回率仍为 100%、误报仍为 0"。
> 评测页的指标会直接显示是否退化。

## 三、看懂审查结果

### 3.1 风险等级

| 等级 | 颜色 | 含义 | 建议动作 |
| --- | --- | --- | --- |
| **高风险** | 红 | 存在实质法律或商业风险，签署后可能造成损失 | **必须整改后再签署** |
| **中风险** | 橙 | 条款不完备或表述不利，可通过谈判修正 | 建议整改后签署 |
| **低风险** | 灰 | 文本规范类问题（如缺金额大写、缺送达条款） | 顺手修订 |

**综合风险等级 = 命中项中的最高等级**；审查结论由等级分布直接推出：

| 条件 | 结论 |
| --- | --- |
| 存在高风险 | **建议拒绝**（若仅 1 条且可整改，可为"建议整改后通过"） |
| 无高风险但有中风险 | **建议整改后通过** |
| 只有低风险或无风险 | **建议通过** |

### 3.2 风险卡片怎么读

每条风险卡包含四块信息，建议按这个顺序看：

| 顺序 | 内容 | 我该怎么用 |
| --- | --- | --- |
| ① | **证据原文**（卡片里的灰底引用） | 先看这句话本身有没有问题 |
| ② | **成因** | 理解为什么它构成风险 |
| ③ | **法律依据**（法条名称） | 判断依据是否成立；必要时自己翻法条 |
| ④ | **推荐修改条款** | 可直接采纳，也可编辑成更贴合业务谈判结果的版本 |

**左上角标签的含义**：`高风险` / `中风险` / `低风险` 是等级；
`HJ-H-002` 这类编号是规则编号（可用于向管理员反馈误报）；
`第 1 页 · 段 #9` 是原文位置。

### 3.3 合同画像雷达图

六维评分（0–100），一眼看出"这份合同哪里虚"：

| 维度 | 含义 | 分数低说明什么 |
| --- | --- | --- |
| 条款完整度 | 8 类必备条款的覆盖比例 | 有必备条款整类缺失 |
| 权责对等度 | 违约责任、保密义务是否对等 | 存在明显不对等条款 |
| 付款安全性 | 付款是否挂钩验收、有无超额预付 | 存在先付款后验收、高比例预付款 |
| 知识产权保护 | 成果权属是否归我方 | 定制成果权属归对方 |
| 争议解决友好度 | 管辖地是否对我方有利 | 管辖约定在对方所在地 |
| 合规文本质量 | 交付、期限、效力等文本规范度 | 表述模糊、要素缺失 |

**综合分**是六项平均。**分数是排序工具，不是结论** —— 最终判断仍要看具体风险项。

## 四、状态说明

### 4.1 任务状态

| 状态 | 含义 | 我要做什么 |
| --- | --- | --- |
| 待处理 | 任务已创建，等待解析 | 稍等 |
| 解析中 | 正在读取合同正文与条款 | 稍等 |
| 审查中 | 正在执行规则判定与语义增强 | 稍等 |
| **解析受阻** | 文档无法解析 | 看原因，见下表 |
| 审查完成 | 结果已生成 | 开始复核 |

### 4.2 解析受阻的六种原因与处置

| 原因 | 屏幕上会看到 | 我该做什么 |
| --- | --- | --- |
| 文档已加密 | "文档已加密，无法解析正文" | 上传**去除密码**的版本 |
| OCR 引擎不可用 | "扫描件正文为空，且 OCR 引擎不可用" | 找管理员安装 OCR 引擎；或提供电子版合同 |
| 扫描件太模糊 | "识别置信度过低（0.xx < 0.35）" | **重新扫描/拍照**，提高清晰度与对比度 |
| 正文为空 | "解析后正文仅 N 字，低于最小阈值" | 确认文件是否为纯图片无文字；换电子版 |
| 解析失败 | "解析失败：……" | 文件可能损坏，换一份；或找管理员查日志 |
| 流水线异常 | "流水线异常：……" | 找管理员查看该任务的审计留痕 |

> **为什么要把"引擎缺失"和"图片模糊"分开告诉我**：
> 因为这两种情况的处理方式完全相反 —— 一个要装环境，一个要换文件。
> 如果只提示"解析失败"，我只能反复点重试然后放弃。

### 4.3 回写状态

| 状态 | 含义 |
| --- | --- |
| 未回写 | 尚未写入审批系统（预览模式下会一直停在这里，这是正常的） |
| 回写中 | 正在提交 |
| **回写成功** | 已写入，评论 ID 会显示在界面上 |
| 回写失败 | 保留错误原因，界面出现「重试回写」按钮 |

### 4.4 人工审核状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 待人工确认 | 审查完成，等法务决策 | 法务选择同意 / 修改 / 驳回 |
| 已确认 | 已同意或修改后确认 | 可以写回审批系统 |
| 已驳回 | 审查结果被驳回，任务已回到"待处理" | 等待重新审查完成后再次复核 |

## 五、常见问题

**Q1：为什么同一个文件我上传两次，第二次说"复用既有任务"？**
系统按文件内容（SHA256）去重，防止重复解析、重复审查、重复写评论。
如果确实需要重新审查，请用工作台里的「重新解析 / 重试」，或让管理员删除旧任务。

**Q2：我点了两次"写回审批意见"，会不会出现两条评论？**
不会。系统用「合同编号 + 文件指纹 + 规则版本号」做幂等控制，
第二次会提示"已回写成功，本次跳过"，评论区仍只有一条。

**Q3：审查结论说"建议拒绝"，系统会替我拒绝吗？**
不会。系统**只写评论区**，不具备任何改变审批结论的能力。
"建议拒绝"只是意见措辞，是否拒绝由审批人决定。

**Q4：有的风险我觉得是误报，怎么办？**
两种做法：① 用「修改后确认」调整或标注；② 记下规则编号（如 `HJ-M-002`）反馈给管理员。
管理员可修改规则并重跑评测，确认不会影响其他合同。

**Q5：合同里有扫描页，会影响识别吗？**
会。扫描件走 OCR，识别质量取决于清晰度。若识别置信度偏低，系统会在报告中附质量提示，
建议对涉及条款人工复核。

**Q6：进度条一直不动是卡住了吗？**
若长时间停在 0%，且底部时间轴也没有新消息，请联系管理员（可能是代理层缓冲了进度流）。
若时间轴在滚动，说明系统在工作。

**Q7：导出的 PDF 打不开 / 中文是方框？**
先试导出 Markdown 版；仍异常请找管理员（PDF 由服务端直出，中文依赖内置字体）。

**Q8：我能一次提交多份合同吗？**
当前需逐份上传。批量上传与队列控制**【未开发】**。

## 六、一页速查卡（可打印）

```
【我要提交合同】  大盘右侧「接入合同」→ 选文件 → 选业务类型 → 等进度条走满
【我要看风险】    工作台 → 右侧风险卡（高风险在最上）→ 点卡片跳原文
【我要反查】      左侧原文划选一段话 → 弹窗看涉及哪几条风险
【我要改措辞】    风险卡 → 采纳建议 → 编辑文本 → 确认
【我要出意见】    「结论与回写」→ 写法务批注 → 人工审核选「同意/修改后确认」
【我要回写】      先「预览意见」确认 → 再「写回审批意见」
【我要报告】      顶栏「导出报告」→「下载 PDF」
【我要改规则】    规则页 → 选规则 → 改 → 保存 → 去评测页跑全量评测
【出问题了】      看状态说明表；解析受阻看「六种原因与处置」
【快捷键】        j/k 切换风险　Enter 采纳　/ 聚焦检索　Esc 退出输入
```
