# 衡鉴 · 可交付运行产物

> **一句话结论**：交付物是一个**开箱即跑**的完整系统 ——
> 双击 `start.bat` 即可启动；已在交付包内附带 13 份样例合同，
> 无需准备任何真实合同数据就能完整演示「解析 → 审查 → 复核 → 回写 → 报告」全链路。

---

## 一、交付物构成

| # | 交付物 | 载体 | 说明 |
| --- | --- | --- | --- |
| 1 | 后端服务 | `backend/`（30 个 Python 文件） | FastAPI + SQLite，含解析/规则/LLM/回写/报告/审计/评测 |
| 2 | 前端控制台 | `frontend/`（10 个静态文件） | 零构建 4 页面：大盘 / 工作台 / 规则 / 评测 |
| 3 | 规则库 | `backend/app/rules/rules_v1.yaml` | 32 条规则，判定唯一来源 |
| 4 | 示范条款库 | `backend/app/rules/clause_templates.yaml` | 14 套标准条款 |
| 5 | 样例合同集 | `backend/samples/` | 13 份（DOCX 9 / PDF 3 / 扫描件 1） |
| 6 | 黄金标注 | `backend/app/eval/golden_cases.json` | 与样例同源生成 |
| 7 | 测试与脚本 | `backend/tests/`、`backend/tools/`、`backend/demo.py` | 39 单测 / 64 冒烟 / 端到端演示 |
| 8 | 部署配置 | `deploy/`、`.github/workflows/ci.yml` | Dockerfile / compose / nginx / CI 四道门禁 |
| 9 | 交付文档 | `docs/`（22 份） | 见《交付文档总览》 |
| 10 | 运行说明 | `README.md`、`CLAUDE.md`、`.env.example`、`start.bat` | —— |

**交付包不含**：`.venv/`（虚拟环境）、`__pycache__/`、`backend/data/`（运行期数据库与报告）、
样例合同的二进制文件可按需附带 —— 因为它们全部可由脚本重新生成。

## 二、一键启动（推荐路径）

```bat
双击 hengjian\start.bat
```

脚本会依次完成：

| 步 | 动作 | 失败时的表现 |
| --- | --- | --- |
| 1 | 检测 uv；缺失则回退系统 Python | 打印警告并继续 |
| 2 | 创建 `.venv`（若不存在） | 报错退出 |
| 3 | 同步依赖 | 打印警告（若已有可用环境可忽略） |
| 4 | 首次运行生成 13 份样例合同与黄金标注 | 报错退出 |
| 5 | 启动 uvicorn 并自动打开浏览器 | —— |

启动后：

| 页面 | 地址 |
| --- | --- |
| 审查大盘 | http://127.0.0.1:8130/ |
| 智能审查工作台 | http://127.0.0.1:8130/pages/workbench.html |
| 合规规则与模板 | http://127.0.0.1:8130/pages/rules.html |
| 评测与观测 | http://127.0.0.1:8130/pages/eval.html |
| 接口文档（Swagger） | http://127.0.0.1:8130/api/docs |

## 三、三分钟验证"真的能跑"

按顺序执行，每步都有可观察结果：

| 步 | 操作 | 期望结果 |
| --- | --- | --- |
| 1 | 打开大盘，点右侧「**从审批系统拉取待办任务**」 | 列表出现 3 条任务，状态从"待处理"依次变为"解析中 → 审查中 → 审查完成"；右侧流水线时间轴逐条点亮 |
| 2 | 打开列表中任意一份**埋雷版**合同 | 进入工作台，左右双栏：左侧合同正文（带页码），右侧风险卡片 |
| 3 | 点右侧「知识产权归属相对方」高风险卡 | 左侧**平滑滚动到第 2 页并高亮脉冲**，该段出现蓝色高亮底 |
| 4 | 在左侧正文里用鼠标**划选**一段文字 | 弹出「片段研判」窗口，显示涉及的风险项（若无则提示未命中） |
| 5 | 点某条风险的「**采纳建议**」 | 弹窗显示推荐条款，可编辑后确认；卡片出现"已采纳"标记 |
| 6 | 切到「结论与回写」标签 | 看到综合风险等级、审查结论、合同画像雷达图、审批关注要点 |
| 7 | 点「**预览意见（DRY_RUN）**」 | 弹窗显示将写入审批系统的 Markdown 正文 |
| 8 | 点「**写回审批意见**」 | 提示"已写回审批系统评论区"，评论区出现该条意见 |
| 9 | 再点一次「写回审批意见」 | 提示"相同文件与规则版本已回写成功，本次跳过"（幂等生效） |
| 10 | 点顶部「**导出报告**」→「下载 PDF」 | 得到一份中文排版的审查意见 PDF |
| 11 | 上传 `samples/13_软件采购合同_加密件.pdf` | 任务变成"解析受阻"，原因明确，点「重新解析 / 重试」仍受阻且不产生脏数据 |

## 四、命令行验证（可复现的证据）

```bash
cd hengjian/backend

# 1. 单元测试：39 项
..\.venv\Scripts\python.exe -m pytest -q

# 2. 接口冒烟：64 项（ASGI 直连，不需要起服务器）
..\.venv\Scripts\python.exe tools\smoke_api.py

# 3. 端到端业务演示：8 步（含异常阻塞与重试）
..\.venv\Scripts\python.exe demo.py --fresh

# 4. 规则回归评测：13 份黄金样例
..\.venv\Scripts\python.exe -m app.eval.run_eval
```

**实测结果**：

| 命令 | 结果 |
| --- | --- |
| `pytest` | **39 passed** |
| `smoke_api.py` | **通过 64 项，失败 0 项** |
| `demo.py` | 8 步全部跑通（含 `CMT-000001` 写入与幂等跳过） |
| `run_eval.py` | 解析成功率 **100%**、高风险召回 **100%**（11/11）、误报 **0**、判定 **PASS** |

产出文件：

- `docs/13_delivery/接口冒烟测试报告.txt`（64 项逐条）
- `backend/app/eval/reports/eval_<时间戳>.md`（评测报告）
- `backend/data/reports/*_审查意见.md` 与 `*.pdf`（报告样例）

## 五、可交付产物的边界（明确不包含的）

| 项 | 状态 | 说明 |
| --- | --- | --- |
| 三角色 RBAC 与登录鉴权 | **【未开发】** | 需求 2.4.2 的权限部分；当前无鉴权，仅适合内网演示 |
| 孪生演示台（单文件 HTML 驾驶舱） | **【未开发】** | 原方案中的演示形态，未实现 |
| 真实审批系统对接 | **【未开发】** | 内置模拟器；适配器位置已预留（`writeback._submit_to_platform`） |
| 服务器 8130 部署 + BossPortal SSO | **【待部署】** | 代码就绪，需现场执行部署与 SSO 配置 |
| 多进程/多实例横向扩展 | **【未开发】** | 事件总线在进程内；扩容需替换为 Redis 或 MQ |
| 第三方盲测集与泛化评估 | **【未开发】** | 当前 100% 召回为**内部回归基线**，非泛化能力证明 |

> 这几项不是"忘了做"，而是有意识地把资源投在了"判定准确性与证据可溯源性"上。
> 每一条都在相应文档中显式标注，避免被误认为已完成。
