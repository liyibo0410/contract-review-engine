## 二、会议确认事项

### 2.1 项目目标（已确认）

建设一个面向企业合同审批场景的智能审查系统，具备以下端到端能力：

1. 支持**多格式**合同文档（Word、PDF、扫描件）解析与条款结构化切分；
2. 通过**大语言模型 + 合规规则引擎**识别法律合规与商业风险；
3. 提供**原文高亮定位、智能修改建议与报告导出**；
4. 支持将审查意见**自动回写**至企业审批系统评论区。

**交付形式**：可运行前端（审查大盘 + 交互式工作台）、后端审查服务、示例合同文件集（覆盖采购、销售、劳动等标准与风险用例）、审批回写模拟模块，以及一条完整演示链路。

### 2.2 开发范围（已确认）

| 序号 | 能力域 | 内容要点 |
| --- | --- | --- |
| 1 | 文档接入与解析 | 对接审批系统待办任务或本地上传；支持 DOCX、PDF 与扫描件 OCR 解析；自动提取合同元数据；完成条款层级切分 |
| 2 | 智能合规与风险审查 | 覆盖主体资质、金额支付、违约责任、知识产权、争议管辖等核心维度；识别必备条款缺失、权责不对等与高风险表述；输出风险等级与合规依据 |
| 3 | 交互研判与建议生成 | 原文与审查意见双向锚定高亮；针对风险条款生成修改建议示范文本；支持法务批注与人工确认 |
| 4 | 审批集成与结果回写 | 最终审查意见与风险摘要自动写回审批系统评论区；支持导出审查意见报告（PDF、Markdown） |
| 5 | 规则与模板管理 | 维护合同分类审查清单、风险等级判定规则、标准示范条款库与阻塞重试机制 |

### 2.3 用户角色与权限（已确认）

| 角色 | 权限边界 |
| --- | --- |
| 法务审查人 | 查看合同审查详情；核对原文高亮证据；采纳或调整修改建议；补充法务意见并触发审批回写 |
| 业务经办人 | 提交合同审查申请；查看合同风险点与整改建议；下载审查报告 |
| 系统管理员 | 配置审批流对接参数；维护合规审查规则与标准条款库；监控审查任务状态并处理阻塞重试 |

### 2.4 页面需求（已确认）

**（1）合同审查大盘页**
展示待审合同列表，字段包含：合同名称、申请人、业务类型、合同金额、审查状态、综合风险等级、创建时间；支持按风险与状态筛选；提供手动上传合同入口。

**（2）智能审查工作台**（三区布局）

- 双栏合同视窗区：左侧展示合同正文（支持文档排版与分页查看），高亮标记风险条款与提取的元数据字段，支持与右侧风险卡片联动精准跳页定位；
- 审查结果与建议区：按高、中、低风险分级展示审查卡片，呈现违规原因、法律依据，并提供 AI 生成的推荐修改条款；
- 审批协同与回写区：展示综合风险评估摘要与审批关注要点，提供法务人工批注输入框、一键回写审批单按钮与导出报告操作。

**（3）合规规则与模板页**
按合同类型（采购、销售、服务、劳动等）维护审查规则项、触发条件、风险分级与标准示范条款库。

### 2.5 审查业务规则与流转机制（已确认）

**（1）任务状态流转**

- 任务状态：`pending`（待处理）→ `parsing`（解析中）→ `reviewing`（审查中）→ `completed`（审查完成），异常时进入 `blocked`（解析受阻）；
- 回写状态：`not_written`（未回写）→ `writing`（回写中）→ `success`（回写成功）/ `failed`（回写失败）；
- 遇到文档加密、扫描件严重模糊或正文为空时，任务流转为 `blocked` 并记录原因，支持人工重新上传或一键重试。

**（2）条款提取与元数据解析**

- 自动提取：签约主体名称、统一社会信用代码、合同金额、币种、履行期限、生效条件等核心元数据；
- 逐段切分：标的物条款、付款进度、验收标准、违约责任、保密义务、数据安全、争议解决管辖等法定与业务条款；
- 溯源要求：**每个解析项必须记录原文起止字符位置、页码与段落索引**，确保双向可溯源定位。

**（3）合规审查判定规则**

综合风险等级分为高、中、低三级。

- 直接判定为**高风险**的情形：主体信息缺失或被列入经营异常；违约责任严重不对等（如我方单方承担无限责任）；管辖地约定违规；未设置付款前置验收条件。
- 判定为**中风险**的情形：缺少保密义务期限；未明确不可抗力通知时效；违约金比例超出法定合理范围。
- 处置要求：针对每个风险点，大模型自动输出替代修改方案（如"双方各承担 50%""违约金不超过合同总额的 20%"）。

### 2.6 前后端模块划分（已确认）

**前端五模块**

1. 大盘与列表模块：任务列表渲染、多条件检索、状态标签与批量操作；
2. 文档视窗模块：PDF/Word 在线预览、文本层高亮渲染、跨页平滑滚动定位；
3. 风险卡片模块：风险等级标签展示、条款差异对比、修改建议一键复制与采纳交互；
4. 协同回写模块：法务批注表单、回写结果状态轮询、审查报告导出预览；
5. 规则配置模块：审查规则树状列表、条件编辑表单与示范条款模板库维护。

**后端五模块**

1. 接入与流转模块：审批系统事件监听、附件去重下载、任务状态机驱动与阻塞重试控制；
2. 文档解析引擎：DOCX 结构解析、PDF 文本抽取、扫描件 OCR 识别，输出分段段落树与元数据；
3. 智能审查引擎：规则模式匹配 + 大语言模型语义研判，执行条款合规性分析并输出风险证据链；
4. 条款推荐引擎：基于标准条款知识库与大模型生成针对性修改建议与改写版本；
5. 审批回写模块：构建格式化审查意见文本，调用审批系统评论接口完成写回并记录回写日志。

### 2.7 核心业务流程（已确认）

**流程一：审批触发与自动审查**

1. 审批系统发起合同审批，推送事件或由审查系统拉取待办任务；
2. 系统下载合同附件并校验完整性，启动文档解析与 OCR 识别；
3. 智能审查引擎提取核心条款，执行规则匹配与大模型合规判定，生成风险卡片与修改建议；
4. 系统计算总风险等级与审查摘要，更新任务状态为审查完成。

**流程二：法务人工复核与协同改写**

1. 法务人员在工作台打开待复核合同，点击风险卡片高亮联动查看原文位置；
2. 核对风险点，确认或调整修改建议，录入补充法务意见；
3. 点击"写回审批意见"，系统将审查摘要与整改建议写回审批单评论区；
4. 系统联动更新回写状态，并允许业务经办人下载整改对比报告。

**流程三：异常任务阻塞与重试**

1. 文档解析异常或接口超时触发阻塞保护，任务进入 `blocked` 状态并推送告警；
2. 管理员在列表页查看阻塞原因，修正文件或调整参数后触发"重新审查"，任务重新进入流转流水线。

### 2.8 审查报告与输出格式（已确认）

- **合同基本信息**：合同标题、合同编号、送审部门、申请人、相对方主体名称、合同金额与履约周期；
- **综合审查结论**：总风险等级（高/中/低）、通过/整改/建议拒绝结论与核心风险摘要；
- **风险清单明细**：风险项名称与等级；涉及条款类型与原文片段定位（页码与段落）；风险成因分析与法律合规依据；推荐修改示范条款；
- **审批回写评论文本**：格式化 Markdown 文本，包含风险总评、需重点关注事项与法务批注。

### 2.9 示例业务场景（已确认）

1. **软件采购合同知识产权与付款风险审查**：审查供应商提供的标准采购合同，识别出"知识产权归属供应商所有"及"到货即付全款无验收条款"两项高风险，系统生成驳回意见并附带保留源代码知识产权与按里程碑付款的修改建议；
2. **大额销售合同违约责任不对等审查**：审查销售合同违约责任条款，识别客户方仅承担每日万分之一滞纳金、而我方承担无上限赔偿责任的非对等条款，系统提示高风险并生成对等赔偿上限示范条款。

**会议决定**：上述场景中**至少任选一个**完成端到端全流程演示。

### 2.10 验收标准（已确认）

系统需同时满足以下 8 条：

1. 能接入并解析 DOCX、PDF 及图片扫描件格式的合同附件；
2. 能准确提取合同核心元数据与主要条款内容，并记录原文页码与位置；
3. 能对必备条款缺失、权责不对等与高危表述完成合规审查，输出风险等级与依据；
4. 能在审查工作台实现原文与风险卡片的双向高亮定位与跳转；
5. 能针对风险条款生成可落地的修改示范条款并支持法务编辑；
6. 能生成格式化审查意见并成功写回审批系统评论区；
7. 解析失败或接口异常时能正确进入阻塞状态并支持重试；
8. 能完成至少一个典型合同的"拉取 → 解析 → 审查 → 复核 → 回写 → 报告导出"演示。

## 五、风险提示与确认事项

**风险提示**

1. **扫描件 OCR 质量风险**：扫描件模糊或排版复杂时，OCR 结果直接影响条款切分与定位精度。当前策略是"严重模糊即进入 `blocked`"，但模糊程度的判定阈值需在开发中实测后固化。
2. **定位精度风险**：DOCX/PDF/OCR 三条解析链路的字符位置体系不一致，需统一换算规则，否则"高亮跳转"会出现偏移。
3. **规则与大模型结论冲突风险**：规则引擎判定高风险、大模型判定低风险时，需明确优先级（建议规则优先，冲突记入待人工复核）。
4. **范围蔓延风险**：本次交付以"可演示、可验收"为边界，真实审批系统的联调不在本次范围内。
