## 一、为什么要加一套「深检」

项目已有 `tools/audit_frontend.py`，查 8 个维度（脚本异常 / 空容器 / 塌陷 / 重复 id /
模板残留 / 横向溢出 / 顶栏重叠），长期报 **0 问题**。但「0 问题」不等于「细节没问题」——
那 8 个维度都是**结构性**的，而用户抱怨的「细节」属于**度量性**的：颜色够不够看得清、
点击区域够不够大、文字被截断后能不能看到全文、屏幕窄了会不会整块顶出去。

于是新增 `tools/audit_frontend_deep.py`，用已有的零依赖 CDP 客户端
（`tools/cdp.py`）**真跑真量**，在 6 页 × 3 视口（1600 / 1280 / 390）上补 10 个维度：

| # | 维度 | 判据 |
| --- | --- | --- |
| 1 | 文本对比度 | WCAG 2.1 AA：正文 ≥ 4.5:1、大字 ≥ 3:1（含祖先背景色求解，遇渐变判为不可判定并跳过） |
| 2 | 触控目标尺寸 | WCAG 2.5.8 AA ≥ 24×24；**含两条规范豁免**（行内目标、间距例外：四周 24px 内无其他目标） |
| 3 | 文本截断无兜底 | `scrollWidth > clientWidth` 且被 ellipsis/hidden 裁掉，又没有 `title`/`aria-label` |
| 4 | 图片缺 `alt` | 读屏软件无法描述 |
| 5 | 表单控件无可访问名称 | 无 `label[for]` / 包裹 label / `aria-label` / `placeholder` |
| 6 | 链接无可访问名称 | 只有图标、没有文字与标签 |
| 7 | 占位链接 | `href=""` / `#` / `javascript:` |
| 8 | 正数 `tabindex` | 打乱自然 Tab 顺序 |
| 9 | 元素越出视口 | 左右任一方向超出，且不在可滚动容器内（装饰层 `.glow/.scanline` 豁免） |
| 10 | 字号过小 | 正文 < 11px |

样式卫生（`!important` / 内联 `style` 计数、`viewport` 是否禁用缩放）作为附注一并输出。
已并入 `python tools/run_all.py`（任务名 `deep`）。

## 二、改动前实测：76 项问题（明细）

| 类别 | 次数 | 典型证据 |
| --- | --- | --- |
| 元素越出视口 | 133 | **`/rules`@390 有 87 项**（整个面板被撑到 1082px 宽）、`/mock`@390 39 项 |
| 触控目标过小 | 76 | 表格复选框 `13×13`；风险卡图标按钮 `22×22` |
| 字号过小 | 55 | 页码 `span.pno` 10.5px、字段名 `span.faint` 10.5px、数据来源 `div.src` 10.8px |
| 文本对比度不足 | 18 | **`span#petBadge` 2.51:1**（需要 4.5:1）—— 六页全中 |
| 文本被截断且无兜底 | 6 | 顶栏副标题 `i`：`scrollWidth 312 > clientWidth 240`，且没有 `title` |
| 表单控件无可访问名称 | 12 | 工作台 6 个 `textarea#sg-*`（推荐修改条款输入框） |
| 占位链接 | 6 | `通知未启用` / `写回评论区`（`href="#"` + `preventDefault`） |

> **为什么原来的体检查不出来**：`/rules`@390 的溢出被 `body` 的 `overflow-x` 遮住了 ——
> `documentElement.scrollWidth` 与 `clientWidth` 相等，于是「横向溢出=否」，
> 但内容是**被裁掉、够不着**的。深检改为逐元素量 `getBoundingClientRect()`，
> 绕开这层遮蔽。这正是「结构性体检」与「度量性体检」的差别。

## 三、修复清单（按根因分组）

### 3.1 品牌口径连锁 bug（本轮改名引入，深检当场逮住）⭐

页面标题一度变成 **「衡鉴 V2.1.6 · 企业衡鉴 V2.1.6」**。根因是改名脚本的**子串二次命中**：
`企业合同智能审查系统` 里含有 `合同智能审查系统`，兜底规则把保护词也一起替换了。
<!-- 注意：本句里的 `合同智能审查系统` 是**被引用的原文**，不能跟着品牌改名一起替换 ——
     v2.1.6 重跑改名杠杆时它曾被误改，已修回。 -->

- 修：改名脚本加**保护词哨兵**机制（替换前把保护词换成 `\x00Pn\x00`，替换完还原）；
  并列出「已被污染的形态」使脚本对跑过一次的树同样可修复。
- 教训写入脚本注释与 CHANGELOG：**任何「全局子串替换」都要先问一句「关键词是否被更长的词包含」**。

### 3.2 窄屏整页横向溢出的两层根因 ⭐

| 层 | 问题 | 修法 |
| --- | --- | --- |
| ① | `rules.html` 用 **行内** `style="grid-template-columns:286px minmax(0,1fr)"` —— 行内声明盖掉 `@media` 的窄屏折叠 | 改为只设自定义属性 `style="--wb-l:286px"`，列宽由 `.wb { grid-template-columns: var(--wb-l, …) }` 取；窄屏折叠仍是普通声明，能正常生效 |
| ② | 窄屏折叠写的是 `grid-template-columns: 1fr` —— `1fr` 的最小值是 `auto`，会被长内容的 min-content 撑开 | 全部改为 `minmax(0, 1fr)`；并补 `.wb > *, .mock-grid > * { min-width: 0 }`（grid 子项默认 `min-width:auto` 同样会撑破轨道） |

同源修复：`.mock-ep .p/.d` 加 `min-width:0` + 折行（接口清单长路径在 390px 顶出视口 24px）。

### 3.3 可访问性

| 问题 | 修法 |
| --- | --- |
| 助手红点 `#petBadge` 对比度 2.51:1 | 底色由 `var(--high)` 改为固定的无障碍红 `#b3261e`（白字在其上 6.5:1），深浅主题都达标；并说明为什么不能直接用主题的「高风险色」 |
| 工作台 6 个 `textarea` 无名称 | 补 `aria-label="推荐修改条款（可编辑，编辑后点「采纳」保存）"` |
| 占位链接 `href="#"` | 改为 `<button type="button" class="as-link">` + 新增 `.as-link` 样式（语义正确、外观不变、带 `:focus-visible` 焦点环） |
| 表格复选框 13×13 | 放大到 16px 并加 4px 外边距，跟随主题色 |

### 3.4 可读性与观感

- 11 处 `font-size: 10.x px` 统一提到 **11px**（app.css 5 处 / fx.css 3 处 / rules.html 1 处，另 2 处同类）。
- 风险卡图标按钮 `22×22 → 24×24`。
- 顶栏副标题英文全称移入 `title`，正文只留中文描述 —— 消除「被截断且无兜底」。
