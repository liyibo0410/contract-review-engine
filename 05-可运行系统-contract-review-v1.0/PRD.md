## 1. 背景与目标

企业合同审批环节中，法务人力有限、业务送审量集中，常见问题有三类：
**必备条款缺失**（无验收条件、无保密期限）、**权责不对等**（我方无限责任、对方封顶免责）、
**高危表述**（管辖地约定不利、违法违约金）。人工逐条核对耗时且标准不统一。

**产品目标**：在审批流程中插入一个自动审查节点 ——
合同附件进入审批后自动完成解析、条款结构化、合规风险识别与修改建议生成，
把「审查意见」写回审批单评论区，让审批人在原审批页面直接看到风险提示，
同时保留法务复核与最终决断权。

**成功判据**：

1. 一份常规合同从附件到审查意见的产出全过程自动完成，无需人工介入；
2. 高风险条款必须带原文定位证据与法律依据，法务可复核、可改、可采纳；
3. 审查意见能自动化回写审批评论区，且**不改变审批结论与流向**；
4. 解析失败等异常不静默失败，而是显式阻塞并可重试。

**非目标（v1.0 明确不做）**：不提供审批决策（通过/拒绝/转交/撤回）、不替代法律意见、
不做合同起草与谈判、不做多租户与权限体系。

## 2. 用户角色与权限

| 角色 | 诉求 | 本版本能力 |
| --- | --- | --- |
| **法务审查人** | 快速定位风险条款、核对证据、给出可落地的修改意见 | 打开工作台查看风险卡片；点击卡片与原文双向高亮定位；编辑并采纳推荐条款；录入法务批注；触发回写；导出报告 |
| **业务经办人** | 知道自己的合同卡在哪、要改什么 | 提交合同送审（本地上传）；在大盘查看合同风险等级与整改建议；下载审查报告 |
| **系统管理员** | 规则可维护、任务可观测、异常可处理、关键事件要能推送到群 | 在规则页按合同类型维护规则项/触发条件/风险分级/标准条款库（保存前校验正则可编译性）；处理 `blocked` 任务并一键重试；在「运行指标」面板查看请求量、错误率、热点接口与慢请求；配置并测试钉钉机器人通知；导出审计数据；执行系统自检 |

> v1.0 为单机演示形态，三种角色的能力在界面上同时开放，未做登录与权限隔离；
> 生产化所需的账号体系与 RBAC 见 `SPEC.md` 第 10 节。

## 3. 页面需求

### 3.1 合同审查大盘页（`/`）

| 区块 | 内容 |
| --- | --- |
| 统计卡 | 审查任务总数、高风险合同数、中风险合同数、审查完成数、解析受阻数、回写成功数、高风险合同累计金额，以及**风险分布堆叠条**（高/中/低/无 占比与图例） |
| 示例合同集 | 折叠面板，列出 8 个示例文件的格式、类别、预期风险与用例说明 |
| 筛选 | 关键词（名称/相对方/单号）、风险等级、审查状态、合同类型 |
| 任务列表 | 合同名称与编号、申请人与部门、业务类型、合同金额、审查状态、综合风险等级、回写状态、创建时间、操作；**点击整行即进入工作台** |
| 批量操作 | 勾选后批量重新审查（失败逐条汇总提示）、批量导出 Markdown 报告 |
| 入口 | 拉取待办并审查、上传合同、一键自检、**机器人通知**、**运行指标**、导出审计数据 |
| 加载与错误态 | 首屏骨架屏；加载失败给出原因与「重试」；空数据显示两个主操作引导 |

### 3.2 智能审查工作台（`/workbench?id=`）

* **页头**：合同标题、单号、来源（审批拉取/本地上传）、审批单号、文件指纹短码、
  审查状态 / 综合风险 / 审查结论 / 回写状态四枚状态标签，以及返回、导出 Markdown、导出 PDF、写回审批意见。
* **双栏合同视窗区（左）**：
  * 按页分页展示合同正文，显示页码与段落序号（`P{页}·{段}`）；
  * 段落左侧标注识别出的条款类型；
  * 命中风险的文字按等级着色高亮（高=红 / 中=琥珀 / 低=蓝）；
  * 点击高亮可反向选中右侧风险卡片，点击卡片可精确跳到对应页码与段落并闪烁定位；
  * 顶部显示文件名、解析引擎、页数/段落数/字符数、OCR 置信度、是否需人工复核。
* **审查结果与建议区（右上，四个页签）**：
  1. `风险清单`：**支持按高/中/低分级筛选、仅看未采纳、单卡折叠/全部折叠**；按高 → 中 → 低排序的风险卡片，
     含风险等级、规则编号、条款类型、匹配方式、原文定位（页码+段落）、原文证据片段（超长可点击展开）、
     风险成因、法律依据、可编辑的推荐修改条款、备选方案（可一键替换）、法务批注输入、
     复制建议、采纳/取消采纳、定位原文；若有风险项**规则库存在无效正则**，顶部给出告警与修复入口；
  2. `条款结构`：条款覆盖度进度条、已识别/未识别条款类型、条款层级清单（序号/条款/类型/页码/段落区间/字数），点行跳正文；
  3. `元数据`：合同标题、编号、送审部门、申请人、相对方、统一社会信用代码、金额、币种、
     履约周期、生效条件、来源、解析引擎与状态、OCR 置信度、页数/段落/字符、文件指纹 SHA256、规则版本、创建时间；
  4. `审计日志`：按时间倒序展示每一步（拉取 → 下载附件 → 计算指纹 → 解析 → 元数据 → 条款切分 →
     规则审查 → 摘要生成 → 回写）的状态与明细。
* **审批协同与回写区（右下）**：
  * 综合风险等级、审查结论、高/中/低计数、风险摘要、审批关注要点、摘要生成方式说明；
  * 法务人工批注输入框（随审查意见一并回写）；
  * 保存批注、预览回写内容、写回审批单、查看审批评论区；
  * 回写状态、评论标识、错误信息、失败重试按钮，以及审批单评论区已写入评论的展示。

### 3.3 合规规则与模板页（`/rules`）

* 左栏：合同类型切换（采购 / 销售 / 服务 / 劳动）、规则统计（总数与高/中/低分级、匹配方式）、条款类型词典（16 类及关键词）。
* 主区：审查规则清单 —— 规则编号、风险项名称、等级、条款类型、匹配方式、触发条件、操作。
* 规则编辑弹窗：编号、名称、等级、匹配方式、条款类型、触发条件（多行）、
  权责不对称的对方一侧条件（pair 模式）、数值比较符与阈值（numeric 模式）、
  风险成因、法律依据、默认推荐修改条款；支持新增与删除。
* 底部：标准示范条款库，按规则编号列出多套备选方案与适用说明。
* 保存：写回 `config/rules/{type}.json`，原文件自动备份为 `.bak`；有未保存修改时切换类型或关闭页面会提示。

## 4. 审查业务规则与流转机制

### 4.1 任务状态流转

```
待处理 pending ──► 解析中 parsing ──► 审查中 reviewing ──► 审查完成 completed
                        │
                        └──► 解析受阻 blocked ──[管理员修正文件 / 一键重试]──► 解析中
```

回写状态：`未回写 not_written → 回写中 writing → 回写成功 success / 回写失败 failed`。

* 文档加密、正文为空、无文本层（图片型 PDF）、OCR 结果过少或置信度不足、不支持的格式、旧版 `.doc`
  → 一律进入 `blocked` 并记录**可读的中文原因**，界面上给出对应处理建议；
* 已成功回写的审查结果不会重复回写（幂等）；回写失败可原地重试。

### 4.2 元数据与条款解析规则

* 自动提取：签约主体名称、统一社会信用代码、合同金额与币种、履行期限、生效条件、合同编号；
* 逐段切分：主体资质、标的物、金额与币种、付款进度、验收标准、交付与履行期限、违约责任、
  知识产权、保密义务、数据安全、不可抗力、争议解决、生效条件、解除终止、税费承担、合规廉洁
  （共 16 类，见 `config/clause_types.json`）；
* **每个解析项都记录原文起止字符位置、页码与段落索引**，保证双向可溯源定位；
* 额外输出「条款覆盖度」：已识别/未识别条款类型数与覆盖率，用于提示可能缺失的条款体系。

### 4.3 合规审查判定规则

综合风险等级 = 所有命中项中的最高等级（高 > 中 > 低）；未命中任何规则时显示「无风险」。

| 等级 | 典型命中情形（内置规则库） |
| --- | --- |
| **高风险** | 知识产权整体归属供应商；到货即付全款且无验收前置条件；相对方主体资质信息缺失；违约责任严重不对等（我方无限责任、对方免责/封顶）；管辖地约定在对方所在地；违法约定违约金或押金；试用期超法定上限；缺少社会保险条款；服务成果知识产权归属不当；服务验收标准缺失；服务费全额预付；回写举证责任严重不利 |
| **中风险** | 违约金比例超出合理范围（阈值可配，默认 > 20%）；缺少保密义务期限；不可抗力未约定通知时效；缺少验收标准；缺少数据安全与个人信息保护条款；加班与休假约定违反法定标准；竞业限制缺少补偿金；缺少质量保证期与售后责任；缺少服务等级与违约责任；缺少服务人员与转委托限制；账期过长 |
| **低风险** | 合同生效条件表述不清；文本存在弹性或非穷尽表述（原则上/尽可能/另行约定等） |

### 4.4 审查结论

| 结论 | 触发条件（`config/app.json` 可配） |
| --- | --- |
| **建议拒绝** | 高风险命中数 ≥ `reject_high_count`（默认 2） |
| **需整改** | 高风险命中数 = 1，或命中总数 ≥ `rectify_total`（默认 1） |
| **通过** | 未命中任何规则 |

### 4.5 风险识别主路径与模型边界

> **风险识别的主路径是确定性的可配置规则（关键词 / 正则 / 必备条款缺失 / 权责对称性配对 / 数值阈值），
> 不是让大模型自由判断合同有没有风险。** 大模型仅用于把已确定的命中结果组织成更自然的中文摘要与评论表达。
> 这样做的原因是：规则结论可解释、可复核、可审计、结果稳定，符合法务场景对「依据」的要求。

## 5. 核心业务流程

### 5.1 审批触发与自动审查

1. 审批系统发起合同审批，推送事件或由审查系统按频率拉取待办；
2. 系统按审批单唯一标识创建任务，已处理过或已回写过评论的审批单自动跳过；
3. 下载附件并计算 SHA256 文件指纹，指纹重复则复用既有审查结果；
4. 按文件头与扩展名路由解析引擎，完成正文、页码、段落位置、表格内容与 OCR 置信度提取；
5. 抽取元数据、切分条款、执行规则审查，生成风险卡片、修改建议与条款覆盖度；
6. 计算综合风险等级与审查摘要，任务状态置为「审查完成」。

### 5.2 法务人工复核与协同改写

1. 法务在工作台打开待复核合同，点击风险卡片联动查看原文位置；
2. 核对风险点，确认或调整推荐修改条款，录入法务批注并采纳；
3. 点「写回审批意见」，系统把审查摘要、风险清单、整改建议与法务批注写入审批单评论区；
4. 系统更新回写状态，业务经办人可下载整改对比报告（Markdown / PDF）。

### 5.3 关键事件通知

审查过程中的关键节点主动推送到群机器人（钉钉），避免高风险合同等人去翻列表：

| 事件 | 触发时机 | 推送内容 |
| --- | --- | --- |
| 高风险合同 | 审查完成且命中高风险 | 合同信息、综合风险与结论、命中的高风险项（含页码） |
| 审查完成 | 任一合同审查完成 | 完整风险统计 |
| 解析受阻 | 文档解析失败进入 `blocked` | 受阻原因与处理入口 |
| 回写失败 | 审查意见未能写入审批评论区 | 失败原因与重试入口 |
| 批量汇总 | 一轮拉取/批量审查结束 | 新建数、高风险数、受阻数汇总（合并为一条，避免刷屏） |

产品约束：

* 每类事件可单独开关，支持「最短发送间隔」防抖、@指定人或 @所有人；
* 兼容钉钉机器人的**加签**与**自定义关键词**两种安全设置；
* **通知是旁路能力**：异步投递，发送失败只记录状态与原因，绝不影响审查主流程；
* 管理员可在界面上看到启用状态、加签配置、发送统计与最近发送记录，并可**一键发送测试通知**
  （失败时直接回显钉钉返回的 `errcode`，便于定位加签/关键词配置错误）。

### 5.4 异常任务阻塞与重试

1. 文档解析异常或接口超时触发阻塞保护，任务进入 `blocked` 并记录原因、在列表页高亮可筛；
2. 管理员查看阻塞原因，按提示修正文件（解密 / 换清晰扫描件 / 另存为 .docx / 调整参数）；
3. 修正后点「重新审查」，任务重新进入流转流水线。

## 6. 审查报告输出格式

| 章节 | 内容 |
| --- | --- |
| 合同基本信息 | 标题、编号、送审部门、申请人、相对方主体、统一社会信用代码、金额、履约周期、合同类别、来源 |
| 综合审查结论 | 综合风险等级、审查结论（通过/需整改/建议拒绝）、风险统计、核心风险摘要、审批关注要点 |
| 风险清单明细 | 风险项名称与等级、条款类型与匹配方式、原文片段定位（页码/段落/字符区间）、原文证据、风险成因、法律依据、推荐修改示范条款、法务批注、处理状态 |
| 条款结构与覆盖度 | 已识别/未识别条款类型、覆盖率、条款层级清单 |
| 审批回写记录 | 回写状态、模式、通道、评论标识、回写时间、错误信息 |
| 法务人工意见 | 法务录入的补充意见 |
| 声明 | 自动生成说明、规则口径说明、不构成法律意见与审批结论的边界声明 |

导出格式：**Markdown**（直接下载）、**PDF**（服务端生成，或浏览器打印另存）、HTML（在线打印预览）。

审批回写评论文本为格式化 Markdown，包含风险总评、需重点关注事项、风险清单明细、法务批注与边界声明。

## 7. 示例业务场景（与内置示例一一对应）

**场景一 · 软件采购合同的知识产权与付款风险**
某核心业务系统采购合同（¥2,860,000），系统识别两项高风险：
软件开发成果知识产权整体归属供应商、到货签收后 5 个工作日一次性付全款且未设验收前置条件。
综合判定高风险，结论**建议拒绝**，并给出「成果归我方所有 + 背景知识产权许可」与
「30/30/30/10 里程碑付款 + 质保金」两套示范条款（各含备选方案）。

**场景二 · 大额销售合同的违约责任不对等**
某年度框架销售合同（¥9,600,000），系统识别：客户方逾期付款仅按每日**万分之一**计滞纳金且
总额封顶 5%，而我方违约需赔偿**包括间接损失在内的全部损失且不设上限**。
综合判定高风险，结论**需整改**，给出对等违约金（每日万分之五）+ 责任上限 100% + 排除间接损失的示范条款。

**场景三 · 劳动用工的违法条款**
某技术研发岗劳动合同，系统识别：约定入职押金 ¥5,000、离职违约金 ¥30,000、试用期 9 个月
（超出法定 6 个月上限），并指出依据《劳动合同法》第 9 / 22 / 25 / 84 条与第 19 / 83 条。

**场景四 · 扫描件合同**
智能制造执行系统采购合同（扫描件 PNG，¥1,530,000），走 Windows 内置 OCR 通道完成识别，
命中「到货即付全款」与「管辖地约定在供方所在地」两项，验证图片型合同的审查能力。

**场景五（异常） · 解析受阻**
图片型无文本层 PDF 与 AES-128 加密 PDF 两个用例，任务进入 `blocked`，
分别提示「建议上传扫描件图片」与「解密后重新上传」，验证异常流转与重试。

## 8. 验收标准

与需求基线（项目实战 2.4.10）逐条对应，实现位置与验证方式见 `docs/验收对照表.md`，
全部 8 条已在 `python run.py --selftest`（33 项细分校验，含通知链路与工程加固项）中真实通过。

1. 能接入并解析 DOCX、PDF 及图片扫描件格式的合同附件
2. 能准确提取合同核心元数据与主要条款内容，并记录原文页码与位置
3. 能对必备条款缺失、权责不对等与高危表述完成合规审查，输出风险等级与依据
4. 能在审查工作台实现原文与风险卡片的双向高亮定位与跳转
5. 能针对风险条款生成可落地的修改示范条款并支持法务编辑
6. 能生成格式化审查意见并成功写回审批系统评论区
7. 解析失败或接口异常时能正确进入阻塞状态并支持重试
8. 能完成至少一个典型合同的拉取、解析、审查、复核、回写与报告导出演示
